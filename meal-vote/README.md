# 식수 투표 시스템

직원이 휴대폰이나 PC 브라우저로 끼니마다 **먹음 / 안먹음**을 투표하고,
식당·담당자는 **현황판**에서 인원을 바로 확인하는 사내 웹 시스템입니다.

## 관리자가 손댈 일이 없는 구조

- **관리자 계정·관리자 화면이 아예 없습니다.** 운영자도 웹에서는 일반 직원과 똑같습니다.
- **마감은 서버가 자동으로 합니다.** 마감 시각이 되면 서버 시계 기준으로 투표가 잠기고,
  그 뒤로는 관리자를 포함해 누구도 앱에서 바꿀 수 없습니다. 직원 PC나 폰 시계를 바꿔도 소용없습니다.
- **직원이 스스로 등록합니다.** 사번·이름·부서·PIN을 직접 입력해 가입하므로 계정을 만들어 줄 필요가 없습니다.
- **현황판은 로그인 없이 열립니다.** 식당에 현황판 주소만 알려 주면 인원을 직접 확인하고
  엑셀(CSV)로 받아 갈 수 있어서 중간에 전달할 필요가 없습니다.
- **변경 이력이 남습니다.** 누가 언제 무엇으로 바꿨는지 데이터베이스의 `vote_log` 표에 쌓입니다.

## 실행 방법

1. 서버로 쓸 PC에 [Python](https://www.python.org/downloads/) 3.9 이상을 설치합니다.
   (설치할 때 "Add python.exe to PATH"를 체크하세요. 그 밖에 따로 설치할 패키지는 없습니다.)
2. 이 `meal-vote` 폴더를 그 PC에 복사합니다.
3. `start.bat`을 더블클릭합니다. (리눅스·맥은 `python3 server.py`)
4. 창에 나온 주소를 직원들에게 알려 줍니다.

```
식수 투표 서버 실행 중 (서버 시각 2026-10-21 08:00)
  직원 투표 화면 : http://192.168.0.10:8080/
  식수 현황판    : http://192.168.0.10:8080/board
```

처음 실행하면 같은 폴더에 데이터베이스 파일 `meal.db`가 자동으로 만들어집니다.

> 다른 PC에서 접속이 안 되면 Windows 방화벽에서 8080 포트(또는 Python)를 허용하세요.

### 꼭 확인할 것

- **서버 PC의 시계가 기준입니다.** Windows 설정 → 시간 및 언어 → "자동으로 시간 설정"을 켜 두세요.
- **서버 PC가 꺼져 있으면 투표할 수 없습니다.** 항상 켜 두는 PC에 설치하고,
  작업 스케줄러에서 "컴퓨터 시작 시" `start.bat`을 실행하도록 등록해 두면 재부팅 후에도 자동으로 켜집니다.

## 설정 (`config.json`)

설정 파일을 고친 뒤에는 서버를 껐다 켜야 반영됩니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `port` | 접속 포트 | `8080` |
| `utcOffsetHours` | 시간대 (한국 = 9) | `9` |
| `openDaysAhead` | 오늘부터 며칠 뒤까지 미리 투표할 수 있는지 | `7` |
| `sessionDays` | 로그인 유지 기간(일) | `30` |
| `departments` | 등록 화면의 부서 목록. 빈 목록 `[]`이면 직접 입력 | 예시 부서 5개 |
| `meals` | 끼니 목록 (아래 참고) | 중식·석식 |
| `holidays` | 식사가 없는 날 (`"YYYY-MM-DD"`) | 예시 2개 |

`meals`의 각 끼니:

| 항목 | 뜻 | 예 |
|---|---|---|
| `id` | 영문 소문자 식별자 (한 번 정하면 바꾸지 마세요) | `"lunch"` |
| `name` | 화면에 보이는 이름 | `"중식"` |
| `cutoff` | 마감 시각 `HH:MM` | `"09:30"` |
| `cutoffDayOffset` | `0` = 당일 마감, `-1` = 전날 마감 | `0` |
| `days` | 식사가 있는 요일 (월=1 … 일=7) | `[1, 2, 3, 4, 5]` |

예) 야간조 야식을 전날 16시에 마감하고 주 7일 운영하려면 `meals`에 다음을 추가합니다.

```json
{ "id": "night", "name": "야식", "cutoff": "16:00", "cutoffDayOffset": -1, "days": [1, 2, 3, 4, 5, 6, 7] }
```

## 웹에 없는 작업 (명령줄)

웹에는 일부러 넣지 않았습니다. 서버 PC에서 이 폴더를 연 명령 프롬프트로 실행합니다.

```
python server.py reset-pin 1001 5678   사번 1001의 PIN을 5678로 재설정 (PIN을 잊은 직원)
python server.py remove-user 1001      사번 1001 퇴사 처리 (로그인 차단, 지난 기록은 보존)
```

## 데이터베이스

- `meal.db` 하나가 전부입니다(SQLite). **백업은 서버를 끈 상태에서 이 파일을 복사**하면 됩니다.
- 내용을 직접 보고 싶으면 [DB Browser for SQLite](https://sqlitebrowser.org/)로 열 수 있습니다.

| 표 | 내용 |
|---|---|
| `users` | 직원 (사번, 이름, 부서, PIN 해시) — PIN은 원문이 아닌 해시로만 저장 |
| `votes` | 날짜·끼니별 현재 응답 |
| `vote_log` | 응답을 바꿀 때마다 쌓이는 이력 |
| `sessions` | 로그인 상태 |

## 보안 관련 참고

- PIN을 5번 틀리면 그 사번은 10분간 로그인이 잠깁니다.
- 사내망 전용입니다(HTTPS 아님). 인터넷에 직접 공개하지 마세요.
- 현황판과 CSV는 로그인 없이 열리므로 사내망에 있는 사람은 누구나 명단을 볼 수 있습니다.
