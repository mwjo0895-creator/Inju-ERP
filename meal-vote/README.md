# 인주공장 식수 투표 시스템

「인주공장 식수인원 조사 및 취합 운영 안내」대로 돌아가는 사내 웹 시스템입니다.
투표 요청, 마감, 집계, 업체 통보, Teams 결과 게시를 사람 손 없이 자동으로 합니다. 투표는 매일 그날 것만 받습니다.

## 하루 흐름 (기본 설정)

| 점심 | 저녁 | 하는 일 | 누가 |
|---|---|---|---|
| 08:00 | 12:00 | 아직 투표 안 한 사람에게 Teams 개인 메시지 (먹음 / 안먹음 버튼) | 자동 |
| 08:45 | 14:15 | 그래도 안 한 사람에게 한 번 더 | 자동 |
| 09:00 | 14:30 | **투표 마감.** 팀별 담당자에게 1차 집계 메시지 | 자동 |
| 09:00~09:30 | 14:30~15:00 | 방문객 등 추가 인원 등록 | 팀별 담당자 |
| 09:30 | 15:00 | **최종 확정.** Teams 채널에 결과 게시, 업체에 메일 | 자동 |

마감과 확정은 서버 PC의 시계로만 판단합니다. 관리자 계정이나 관리자 화면은 없고,
마감이 지나면 누구도 앱에서 바꿀 수 없습니다. 미투표자나 마감 뒤 투표자는 안내문대로 식사 인원에서 빠집니다.

## 누가 누군지 어떻게 아나요?

**직원마다 본인만 아는 개인 링크가 있습니다.** Teams 메시지의 [먹음] / [안먹음] 버튼에 그 링크가 들어 있어서,
버튼을 누르면 로그인 없이 그 사람으로 투표됩니다. 비밀번호도, 회원가입도 없습니다.
한 번 누르면 브라우저가 1년 동안 기억하므로, 그다음부터는 투표 화면 주소로 바로 들어와도 됩니다.

메시지를 지웠거나 다른 PC·휴대폰에서 들어갈 때는 **로그인 화면**에서 이름을 고르고 [Teams로 접속 버튼 받기]를 누르면 됩니다.
그 사람의 Teams로 [식수 투표 열기] 버튼이 가고, 본인만 받을 수 있으므로 비밀번호가 필요 없습니다.
(같은 사람에게는 1분에 한 번만 보냅니다. 이메일이 없는 사람은 보낼 수 없다고 나옵니다.)

반발을 줄이려고 이렇게 했습니다.

- 로그인·가입 없음. 메시지 버튼 한 번이면 끝납니다.
- 이미 투표한 사람에게는 메시지를 보내지 않습니다. 알림은 아직 안 한 사람에게만 갑니다.
- 화면에는 오늘 점심·저녁 두 줄만 나옵니다. 고를 것이 그것뿐입니다.
- 마감 전까지는 몇 번이든 바꿀 수 있습니다.

## 설치

1. 항상 켜 두는 사내 PC에 [Python](https://www.python.org/downloads/) 3.9 이상을 설치합니다.
   설치 첫 화면의 "Add python.exe to PATH"를 체크하세요. 그 밖에 따로 설치할 것은 없습니다.
2. 이 `meal-vote` 폴더를 그 PC에 복사합니다.
3. **명단 파일 `roster.csv`를 이 폴더에 넣습니다.** 이 저장소는 공개 저장소라서 실제 명단은 올리지 않았습니다.
   형식은 `roster.example.csv`를 보세요. 엑셀로 열어 고치고 그대로 저장하면 됩니다.
4. `roster.csv`의 **이메일** 칸을 채웁니다 (Teams 로그인 주소). 비어 있으면 그 사람에게는 Teams 메시지가 가지 않습니다.
5. `config.json`의 `vendor.to`에 업체 메일 주소를 넣습니다.
6. [TEAMS_SETUP.md](TEAMS_SETUP.md)대로 Teams 워크플로를 한 번 만들고, 나온 주소를 `config.json`의 `webhookUrl`에 넣습니다.
7. `start.bat`을 더블클릭합니다. 방화벽 창이 뜨면 "액세스 허용"을 누르세요.

> **처음 켤 때는 업무 시간이 끝난 뒤(저녁)에 켜는 것을 권합니다.** 확정 시각 1시간 안에 켜면 그 끼니 확정 통보가 바로 나갑니다.

`webhookUrl`이 비어 있는 동안에는 메시지를 실제로 보내지 않고 `outbox.log`에 적기만 합니다.
무엇이 나갈지 미리 확인할 때 쓰세요.

## 팀별 담당자

`roster.csv`의 **담당자** 칸에 `O`가 있는 사람입니다.

- 투표 마감(09:00 / 14:30)에 1차 집계가 Teams로 옵니다. [추가 인원 등록] 버튼을 누르세요.
- 투표 화면의 각 끼니 아래 **+ 추가 인원**에 인원수와 특이사항(예: `음봉 생산팀 교육 방문`)을 적고 저장합니다.
  확정 시각(09:30 / 15:00)까지 고칠 수 있습니다. 그날 아침부터 등록할 수 있습니다.
- 추가 인원이 없으면 아무것도 안 해도 됩니다.

## 현황판과 정산

현황판 `http://서버주소:8080/board`은 로그인 없이 열립니다.

- **일별**: 오늘(또는 고른 날짜)의 끼니별·분류별 인원, 특이사항, 먹는 사람 명단. 날짜를 바꾸면 지난 현황을 볼 수 있습니다.
  **이날 명단(CSV)** 은 그날 직원별 응답과 추가 인원입니다.
- **월별**: 그달 날짜별 점심·저녁 인원과 분류별 합계. 합계는 확정된 끼니만 셉니다. 날짜를 누르면 그날 일별 현황으로 갑니다.
  **정산용 CSV** 는 날짜·식사·분류별 정기/추가/합계로, 월별 식대 정산 엑셀에 붙여 넣으면 됩니다.
  SharePoint 엑셀에 자동으로 쌓고 싶으면 [TEAMS_SETUP.md](TEAMS_SETUP.md)의 선택 단계를 보세요.

## 명단이 바뀌면

`roster.csv`만 고치면 됩니다. 서버가 20초 안에 알아서 다시 읽습니다 (껐다 켤 필요 없음).

- **번호는 한 번 정하면 바꾸지 마세요.** 번호로 같은 사람인지 알아봅니다. 새 사람은 새 번호를 씁니다.
- 줄을 지우면 그 사람은 더 이상 들어올 수 없고 메시지도 안 갑니다. 지난 기록은 남습니다.
- 분류는 집계 단위입니다. 담당자의 분류에 추가 인원이 붙습니다.

## 개인 링크 관리 (명령줄)

서버 PC에서 이 폴더를 연 명령 프롬프트로 실행합니다.

```
python server.py links          모든 직원의 개인 링크 출력 (Teams 연결 전에 직접 나눠 줄 때)
python server.py new-link 7     7번 직원의 링크를 새로 발급 (링크가 남에게 넘어갔을 때, 예전 링크는 바로 막힘)
python server.py send-test 내주소@회사.com   Teams 개인 메시지·채널·메일 연결 시험
```

## 설정 (`config.json`)

고친 뒤에는 서버를 껐다 켜야 반영됩니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `siteName` | 메일 제목 앞에 붙는 이름 | `인주공장` |
| `port` | 접속 포트 | `8080` |
| `baseUrl` | Teams 메시지 버튼에 넣을 서버 주소. 비우면 이 PC의 IP로 자동 | `""` |
| `remindMinutesBefore` | 마감 몇 분 전에 다시 알릴지. `0`이면 안 보냄 | `15` |
| `meals` | 끼니별 `notifyAt`(알림), `cutoff`(투표 마감), `finalAt`(확정·통보), `days`(요일, 월=1 … 일=7) | 점심·저녁 |
| `holidays` | 식사가 없는 날 (`"YYYY-MM-DD"`) | 예시 2개 |
| `webhookUrl` | Teams 워크플로 주소 ([TEAMS_SETUP.md](TEAMS_SETUP.md)) | `""` |
| `vendor.to` / `vendor.cc` | 업체 메일 받는 사람 / 참조 | `[]` |

## 꼭 확인할 것

- **서버 PC의 시계가 기준입니다.** Windows "자동으로 시간 설정"을 켜 두세요.
- **서버 PC가 꺼져 있으면 아무것도 안 됩니다.** 작업 스케줄러에 "컴퓨터 시작 시 `start.bat` 실행"을 등록해 두세요.
  꺼져 있다 켜지면 놓친 알림 중 아직 시간이 남은 것만 보냅니다 (확정 통보는 1시간까지).
- **사내망에서만 열립니다.** 회사 와이파이가 아닌 휴대폰에서는 Teams 버튼을 눌러도 화면이 열리지 않습니다.
- 개인 링크는 그 사람의 열쇠입니다. 남에게 넘어갔으면 `new-link`로 새로 발급하세요.
- 현황판은 로그인 없이 열리므로 사내망에 있는 사람은 누구나 명단을 볼 수 있습니다.

## 데이터베이스

`meal.db` 파일 하나가 전부입니다 (SQLite). 서버를 끈 상태에서 이 파일을 복사하면 백업입니다.
[DB Browser for SQLite](https://sqlitebrowser.org/)로 열어 볼 수 있습니다.

| 표 | 내용 |
|---|---|
| `users` | 명단 (roster.csv에서 자동으로 채움) |
| `votes` / `vote_log` | 현재 응답 / 바꿀 때마다 쌓이는 이력 |
| `extras` | 담당자가 등록한 추가 인원과 특이사항 |
| `notices` | 보낸 알림 (같은 알림을 두 번 보내지 않으려고) |

python -m unittest test_server

발송 실패 재시도, 명단 파일(엑셀 CSV 두 가지 인코딩)을 확인합니다.
